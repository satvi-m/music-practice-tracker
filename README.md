Music Practice Tracker

Project goal:
As a pianist, I need to keep track of my practice habits, including when I practice, how long my sessions are, and what I practice. From my experience and that of others, it becomes disorganized to track everything in a regular notebook, so it would be more convenient to have one area where everything can be logged and tracked. Words of motivation would be uplifting too, especially during times when I don't have the drive to begin practicing and persist due to laziness or lack of energy. 

MVP Scope:
• logging practice sessions
• setting a goal for practice hours for a week
• get words of motivation for practicing when encouragement is needed
• making a to-do list to plan practice sessions
• view practice history

Tech Stack:
• python3
• Visual Studio Code
• Github
• JSON for storing files

Future Plans:
• Implement a way to track practice history and get practice statistics
